# Atividade 1

## O que é uma regra CSS?

Uma regra CSS é uma instrução que diz quais elementos estilizar e como estilizá-los. Ela é formada por um seletor e um bloco de declarações entre chaves. Cada declaração é um par propriedade: valor.

### Exemplo

```css
p {
    color: blue;
}
```

- **Seletor:** `p`, ou seja, todos os parágrafos
- **Propriedade:** `color`, a cor do texto
- **Valor:** `blue`, azul

Resultado: todos os parágrafos da página ficam com o texto azul.
